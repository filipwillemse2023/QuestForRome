# description
a new feature needs to be added to the projectiles: explosions. On a projectile type, it should be possible to check a checkbox that the projectile ends in an explosion. When checked, we can define an extra animation for the actual explosion. We can also define a hitbox for the explosion itself, this determines the area of damage, and a damage value for the explosion itself which can be different than the projectile itself (the projectile can be damage 0 and the explosion can have a damage > 0 for example, so we can create something like a bomb that can be placed on the ground, is harmless for a certain duration, then explodes and damages on exploding). We can also indicate that the explosion does not hurt the creator, this means that when the player launched the exploding projectile, it will only hurt enemies and if an enemy created the projectile, it will only hurt the player.
To accomodate using this concept to create a bomb weapon, make a new projectile movement type: "place", for thus type we have two parameters, both durations in seconds, the first duration just shows the projectile lying still at the spot where it was placed, doing nothing, when that duration ends and the second duration is > 0, then the projectile will still lie still at the same spot, but start blinking for the duration in the parameter. After that, the projectile explodes.
