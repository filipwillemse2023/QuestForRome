# description
in the data/sprites/text folder, there is a png file containing sprites for letters, numbers and characters plus an image of the text area below it. The letters, numbers and characters are all 8x8 sprites, the text area is a drawing below that. We will use the images to display text in the game. Like the HUD at the top of the screen, add a blank area below the play area. 

As soon as text needs to be displayed, the text area graphic then appears in the middle of this zone and the text will start appearing letter by letter in this text area, top to bottom, left to right (speed should be defined in a global variable as letters per second). Text can either be triggered by interacting with an NPC (functionality that still needs to be implemented) or on a map room we can set a property "Display text" - checkbox in the map editor with then a textarea that can be filled in with the text to be shown - and when this is active for a room, show the text as soon as the player enters the room. When all the text has appeared for a room text, leave it on screen until the player leaves the room, then hide the text area and letters in it.
