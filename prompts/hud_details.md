# description
The HUD (the top section of the screen with health, weapons and coins) needs to be changed slightly: for money there is now a system of yellow squares for each coin collected, this needs to be changed to a coin image, then a X and then the actual amount of money in numeric characters. Also, this should be shown at the right hand side of the HUD. 
Then a new function needs to be added: a "start menu", i.e. when pressing the Start button (a new type of button to be added, use the enter key by default), the game should pause and the start menu should scroll on top of the game area. This start menu consists of three zones: the left 60% of the screen width will be taken in by weapon slots, i.e. sections like the A and B button weapons in the HUD that can be empty of contain a weapon that the player owns (for testing, always give the player all available weapons). The player can then move through those slots with the arrow keys to select them and press the A or B button to switch the current weapon in the corresponding active weapon slot with the weapon in the selected slot of the start menu. When no weapon is present in the selected slot, the active weapon will just become empty (which means that acttack button does nothing) and the other way around when the active weapon is empty at the time of switching with a start menu slot, that start menu slot will become empty.
On the right side of the screen, the top half of the screen will be reserved for important items (these do not exist yet, but they will be pickup items that will grant the player some upgrade or special power and these are passive powers). At the bottom half there will be a big heart image that can contain 1, 2 or 3 quarters of four heart pieces, these will represent the collected heart pieces (there will be a powerup "heart piece", each time the player picks up one of those heart pieces, another quarter of the heart will be added until the player has collected four, then he will get another heart container and the number of heart pieces will go back to 0).
When pressing the start button inside the start menu, the start menu scrolls back up off the screen and the game continues.
